# Sales Dashboard – Excel Project

## 📊 Project Overview
This project is an interactive Sales Dashboard built using Microsoft Excel. It provides insights into sales performance, revenue, orders, product categories, and regional sales.

## 📁 Workbook Structure

The Excel workbook contains three sheets:

- **Sales_Data:** Raw sales transaction data containing 2,000 records.
- **Supporting_Pivots:** Supporting PivotTables used for data analysis.
- **Sales_Dashboard:** Dashboard for visualizing and monitoring sales performance.

## 🛠️ Tools & Skills Used
- Microsoft Excel
- PivotTables
- Data Analysis
- Data Visualization
- Interactive Dashboard Design

## 🎯 Project Objectives
- Analyze overall sales performance.
- Understand regional sales distribution.
- Compare sales across different channels.
- Identify product category performance.
- Track key sales metrics and trends.

## 📂 Project File

`Salws_dashboard(1).xlsx`

## 🚀 How to Use
1. Download the Excel workbook.
2. Open it using Microsoft Excel.
3. Navigate to the **Sales_Dashboard** sheet.
4. Explore the dashboard and its available insights.
